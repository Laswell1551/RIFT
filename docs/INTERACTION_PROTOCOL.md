# Independent road continual-learning extension

Fixed before training, after inspecting release shapes and timing a random-tensor forward/backward pass (no validation-based model selection).

- Source: INTERACTION processed release linked by the official H2C repository, https://github.com/BIT-Jack/H2C-lifelong and its Google Drive data folder. Reuse verified local copies and download missing train files. Preserve the original train/validation split. The validation set was previously used for the disclosed constant-velocity diagnostic; it is not a newly blind test set.
- Follow the release's eight-domain order MA, FT, LN, ZS2, OF, EP0, GL, ZS0. Draw a fixed uniform sample of at most 2,000 official training examples per domain using seed 20260915 plus the domain index. All methods/seeds use exactly these samples. Evaluate every released validation example, with no outcome-based filtering.
- Use the released UQnet VectorEncoder end-to-end, including trajectory subgraphs, map subgraphs, lane connectivity and global interaction attention. Keep its layer structure; set channel width to 64 for the CPU compute budget. Replace the heatmap decoder with a deterministic two-coordinate residual endpoint head. Name the model **UQnet-encoder regression adaptation**, not the original UQnet benchmark result, HiVT, or a reproduced state-of-the-art score. Forecast the released 3 s endpoint; do not manufacture intermediate trajectory labels.
- Four methods: fine-tuning, reservoir, gradient-diverse replay (GSS-adapted), and two-support replay. Use 500-example memories, three epochs per domain, batch 64, AdamW 0.001/weight decay 1e-4, normalized SmoothL1 and gradient clipping 5. Replay one stored example per current example per epoch (20/80 branch draws for two-support); all replay methods use equal optimizer-step budgets. Store original example IDs as replay references; selection never sees validation data.
- Seeds 7, 11, 23, 47. After each domain's actual parameter updates, evaluate all domains seen so far and save the entire lower-triangular error matrix plus diagonal/final per-example predictions. Four seeds describe training variability conditional on the fixed domains and subset, not population-level domain uncertainty.
- Fix the same observed CPA threshold <4 m and 3 s horizon as the earlier diagnostic. Compute CPA from observed target/neighbor positions and velocities; no future coordinate enters the mask. Define smooth selection weight exp(-d_CPA/8 m), corresponding to exp(-normalized_d/2) with normalized_d=d_CPA/4 m. No-neighbor cases remain in ordinary FDE and are excluded only from the CPA subset by infinite distance.
- Primary measures: ordinary and CPA endpoint FDE, their immediately-after-learning-to-final changes, and CPA-minus-ordinary forgetting. Average over historical domains equally (first seven domains). Retain all domain/method outcomes; use 20,000 paired seed-bootstrap resamples with four-seed intervals labeled explicitly.
- Check source hashes, data dimensions, finite values, valid neighbor counts, and exact train/validation duplicate input-target examples. Record the data/preparation/code manifests. Do not treat this road study as real low-altitude validation or closed-loop safety validation.
